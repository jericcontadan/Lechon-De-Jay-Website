# Lechon De Jay: Web-Based Ordering and Management System

Website and ordering system for **Lechon De Jay**, a Filipino lechon store in Casimiro Westville, Ligas 2, Bacoor City, Cavite. Open daily 10 AM to 10 PM for dine-in and takeout.

Web Development Project (BSIS 3C-M), Phase 1. Built with **HTML and CSS only** as a static website prototype.

## Features

- Static home, about, menu, gallery and contact pages
- Static registration, login, reservation and event-booking form mockups
- Sample cart, order history, profile and admin pages
- Responsive navigation and layouts using CSS
- Ordering, account management, payments and form processing are planned for Phase 2

## Run locally

1. Install Visual Studio Code and the **Live Server** extension.
2. Open this folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**.

## Design

- Colors: Roast Red `#B5361B`, Deep Brown `#3B1F14`, Golden `#E9A23B`, Warm White `#FBF3EE`, Charcoal `#2B2B2B`
- Fonts: Playfair Display (headings) and Open Sans (body)
- Responsive for phone, tablet and desktop; the admin pages are tablet-first
- Semantic HTML, alt text, labeled forms, keyboard use and visible focus outlines

All pages are static prototypes. Forms do not submit to a service, and ordering or account data is not saved. Future phases may add a server, order processing, payment gateway, inventory and point-of-sale integration, and loyalty rewards.
