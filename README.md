# Project Overview

Lechon De Jay is a static web-based ordering and management prototype for a Filipino lechon store in Casimiro Westville, Ligas 2, Bacoor City, Cavite. The store is open daily from 10 AM to 10 PM and offers dine-in and takeout.

## Purpose

This project presents the store's menu, services, reservation and event-booking information, and prototype ordering and account-management interfaces.

## Features

- Responsive home, about, menu, gallery and contact pages
- Menu category filtering and item-name search
- Form validation with accessible inline errors
- Shopping cart with localStorage persistence
- Cart item count badge, quantity controls, removal and peso totals
- Checkout confirmation modal
- Store open/closed status in Asia/Manila time
- Reservation, event-booking, order, profile and admin page mockups
- Responsive navigation, keyboard support and visible focus outlines

## Design Concept

- Roast Red: `#B5361B`
- Deep Brown: `#3B1F14`
- Golden: `#E9A23B`
- Warm White: `#FBF3EE`
- Charcoal: `#2B2B2B`
- Typography: Playfair Display for headings and Open Sans for body text
- Layout: Responsive card-based pages with semantic HTML, accessible forms and consistent spacing

## Deployment

- Repository: https://github.com/jericcontadan/Lechon-De-Jay-Website
- Live site: https://jericcontadan.github.io/Lechon-De-Jay-Website

## How to Run Locally

1. Install Visual Studio Code and the Live Server extension.
2. Open the project folder in VS Code.
3. Right-click `index.html` and select **Open with Live Server**.

## Lessons Learned

- Semantic HTML and accessible labels improve the usability of static prototypes.
- Responsive layouts and reusable CSS classes keep 13 pages visually consistent.
- Vanilla JavaScript can provide validation, filtering, localStorage persistence and dynamic status updates without external libraries.
- GitHub Pages can host and deploy the static site directly from a repository.
- Clear content placeholders and asset checks help prevent broken pages.
